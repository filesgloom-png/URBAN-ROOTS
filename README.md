# URBAN ROOTS

Realistic 3D life-simulation prototype for Android, built with Godot 4.5.1 and GDScript.

## First milestone
- Procedural 3D starter apartment
- Controllable third-person character
- First-person / third-person camera toggle
- Touch controls for Android and keyboard controls for desktop testing
- GitHub Actions Android debug APK export

## Build
GitHub Actions runs on pushes to `main` and can be started manually. The exported APK is published as the `URBAN-ROOTS-debug` workflow artifact.

This is an early prototype: visuals are procedural placeholder geometry, not final production assets.
